# Fieldnote

Fieldnote is a mobile-first crop-health research prototype for cassava and maize. It includes photo capture, symptom notes, an installable PWA, and preliminary on-device image classification.

## Run the prototype

Python's standard library serves the app locally; no Python packages or AI credentials are required:

```powershell
python server.py
```

Open `http://127.0.0.1:8000/`. The browser loads the ONNX Runtime Web engine and the small quantized model from the app's own `assets` folder. On first load, wait for the service worker to finish caching the app; the ONNX model and WebAssembly runtime are about 13 MB together. After they are cached, photo classification can run offline. The photo is processed in the browser and is not sent to the Python server or an inference provider.

To see a result, select cassava or maize, choose a photo, optionally select the visible symptom, then tap **Analyze photo & get recommendations**. The app displays its closest model class, explains when that class cannot be used for the selected crop, and shows practical next steps. When the model result is uncertain, next steps are tailored to the selected symptom; they are not a diagnosis or model-generated treatment. Results are not produced by simply selecting a photo.

The PWA is intended for current Android and iPhone browsers. Installation and offline caching require an HTTPS deployment; `localhost` is the local-development exception. For online phone access, publish the static app files (`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `service-worker.js`, and `assets/`) at the web root of an HTTPS static host. No inference server is needed for this research prototype. Keep the phone connected while the app and model are first downloaded; the browser may later evict offline data to free storage.

## Research model and limitations

The bundled prototype model is [Gopina/maize-disease-classifier](https://huggingface.co/Gopina/maize-disease-classifier), pinned to repository commit `812be29a9806d94f2d9a2cb84bc09b69b7974e62`. The repository declares an MIT license in its metadata but does not include a license file; verify reuse rights before a public release. The ONNX MobileNetV3-Small model returns five classes: healthy, maize rust, maize blight, cassava mosaic, and bean spot. Fieldnote only displays the healthy class or a class matching the crop the user selected; it refuses a top result that belongs to another crop.

The model card describes 300 images per class from PlantVillage and Cassava Leaf Disease datasets, but does not provide an independently reproducible evaluation protocol. Its stated F1 values differ between the README and `model_meta.json`. It has **not** been independently evaluated on Ugandan farm photos. Cassava brown streak disease and many other serious crop conditions are not model classes. Results are a raw model score, not a calibrated probability. This is a research prototype for testing the app flow, **not a reliable diagnosis or a basis for treatment**. Ask a qualified local extension worker to confirm suspected problems; never spray or remove plants based on its output.

Advice shown beside a result is cautious field guidance, not generated by the image model. For a high-scoring class that matches the selected crop, the app displays class-specific checks and follow-up steps. Uncertain or unsupported results receive symptom-specific field checks and safe steps to seek confirmation. The file upload, optional symptoms, and location are not sent to a server. The photo is only used in browser memory for the current classification.

The browser runtime is [ONNX Runtime Web](https://github.com/microsoft/onnxruntime), pinned to version 1.22.0. Before releasing this publicly for farming decisions, verify model and dataset licensing, test current Android and iPhone devices, and evaluate with expert-labeled images from Ugandan farms and the target growing regions.

## Uganda-first model scope

The intended crop sequence is cassava and maize first, followed by banana (including matooke). The research model currently covers only cassava mosaic, maize rust, maize blight, and a healthy-looking class. Other classes, crops, animal cases, and locally validated recommendations require separately reviewed models and data.

## Visual identity

The header, favicon, and footer use the red-and-navy shield/insect logo selected from the first supplied logo sheet. The supplied farm photo is used as the softened page-wide background. Scouting and leaf-pest photos appear in the guidance panel. These images are illustrative only and are not used by the model.

## Before real-world use

Obtain permissioned, labeled field images from Uganda for the target crops and have local agronomists verify labels. Evaluate on held-out farms, phones, seasons, and districts—not only a random split of the training dataset. Have local experts review every recommendation, confidence thresholds, and escalation guidance. Clearly route uncertain or severe cases to local agricultural extension services. Never recommend pesticide use without locally approved, label-compliant guidance.

The included server binds to `127.0.0.1` by default for local development. Serve a public PWA over HTTPS and review consent and privacy requirements before release.
